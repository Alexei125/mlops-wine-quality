# mlops-wine-quality
## Эксперименты с моделями

Были протестированы две модели: **LinearRegression** и **RandomForestRegressor**. 
Для каждой модели фиксировался `random_state=42` для воспроизводимости.
Трекинг экспериментов выполнялся в **MLflow**.

### Сравнительная таблица результатов

| Модель | Параметры | MAE | MSE | RMSE | R² |
|--------|-----------|-----|-----|------|-----|
| LinearRegression | — | 0.5035 | 0.3900 | 0.6245 | 0.4032 |
| RandomForest | n_estimators=50, max_depth=5 | 0.4908 | 0.3724 | 0.6102 | 0.4302 |
| RandomForest | n_estimators=100, max_depth=10 | 0.4447 | 0.3182 | 0.5641 | 0.5131 |
| **RandomForest** | **n_estimators=200, max_depth=None** | **0.4251** | **0.3059** | **0.5531** | **0.5319** |

### Обоснование выбора

Лучшей моделью признан **RandomForestRegressor** с параметрами 
**n_estimators=200, max_depth=None**. Он показал наименьшую ошибку 
(MAE=0.4251, MSE=0.3059, RMSE=0.5531) и наибольший коэффициент 
детерминации R²=0.5319. 

Модель устойчива к переобучению и хорошо улавливает нелинейные 
зависимости в данных о качестве вина, в отличие от LinearRegression.
